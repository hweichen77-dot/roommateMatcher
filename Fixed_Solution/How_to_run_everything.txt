You'll be using terminal for most of the steps so make sure you have it open.
Mac instructions are first, Windows instructions are at the bottom.

If you dont know what terminal is its a app that lets you run commands within your system. Press cmd + space and then type terminal and press enter to access it. 

MACOS

1) install g++(c++ compiler) and python3

for g++, just type xcode-select --install into the terminal and press enter
for python3, go to https://www.python.org/downloads/ and download/intstall python3 from there 

to double check that you installed everything, run python3 --version and g++ --version

2) Move all the files from Fixed_Solution into a seperate folder and then move that folder under the current user or the desktop. For example, I would place my folder under the user JasonHuang. This is since the terminal will only access files from the user that is currenly logged in. 

Link for downloading all the files: download this repository, everything you need is in the Fixed_Solution folder.

3)install the openpyxl library with the command pip3 install pandas openpyxl

Alright now you can acutally run everything 

4)Open terminal, and type in cd /path/to/your/folder (replace /path/to/your/folder with the acutal directory of your folder. For example, if my folder was on my desktop I would replace it with 
cd ~/Desktop/folder_name. Make sure to replace folder_name with whatever your folder is called. Preferably make the name just one word)

5)Run the following commands in order:

chmod +x run.sh
chmod 644 students.csv
./run.sh

6)Check the results

There should be 4 new files within the same folder:

errors_raw.csv (raw list of errors passed on from error_detector.cpp to generate_report.py)
error_report.xlsx (detailed report of all the errors)
room_assignments.csv (final room assignments)
Students_corrected.csv (fixed students.csv file)

WINDOWS

Use PowerShell for these. Press the Windows key, type powershell, and press enter.

1) Install python and g++ (only needed once):

winget install -e --id Python.Python.3.12
winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT

Close PowerShell and open it again so it can find the new programs. To double check, run py --version and g++ --version

2) Download this repository, unzip it, and go to the Fixed_Solution folder. For example, if you unzipped it to your Downloads folder:

cd $HOME\Downloads\roommateMatcher-main\roommateMatcher-main\Fixed_Solution

3) Run it:

.\run.bat

It installs pandas and openpyxl for you, then makes all the files except the roommate assignments.

Use run.bat on Windows and skip the commands from the Mac steps. If you type .\error_detector.exe > errors_raw.csv into the default PowerShell yourself, it saves the file as UTF-16 and the next step crashes. run.bat avoids that.

4) Run the roommate assignment code

Open the roommateMatcher (located within your Fixed_Solution folder) in powershell then it will start running.
